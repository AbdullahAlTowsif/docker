Linux Basic Commands
--------------------
1. present working directory --> pwd
2. list --> ls, ls -l, ls -a, ls -la
3. change directory --> cd
4. mkdir --> make a new folder
5. touch filename --> create a file
6. rm filename --> remove the file
7. cat filename --> see the contents of the file
8. head/tails -n filename e.g. head -n 6 a.txt (here 5 means first 5 lines)
9. echo >> filename --> file er sathe add hoy content
10. echo > filename --> append new content previous content removed e.g. echo hello world > a.txt
11. rm foldername --> removes a folder
12. rm -rf foldername --> removes a folder forcefully
13. mkdir -p folder1/folder2 --> creates a folder inside another folder at the same time
14. cp file1.txt file2.txt --> copies file1 contents inside file2
15. cp -r folder1/ folder2/ --> copies everything from folder1 to folder2
16. mv filePrv.txt fileNew.txt --> renames filePrv to fileNew

### Permission Group ###
** ls -l ---> to see the permission

rwx => r= read, w=write, x=execute
Here, rw-rw-r-- ==> (rw-)user, (rw-)group, (r--)others
Let's explain this one: -rw-rw-r-- 1 towsif towsif    0 Sep  8 18:36 a.txt
Here,
- = Regular file
rw-rw-r-- = File permissions
1 = Number of hard links
towsif = owner(user)
towsif = Group
0 = File size by bytes (empty file)
Sep 8 18:36 = Last modified date and time
a.txt = File name

First towsif --> user --> read, write but NO execute
Second towsif --> group --> (if any other users stays in this group like userX) --> read, write, NO execute
Finally, others --> read, but NO write & execute.

Let's explain this one now: drwxrwxr-x 2 towsif towsif 4096 Sep  8 18:36 files
Here,
d = directory
drwxrwxr-x = permissions
2 = Number of links to the directory
towsif = Owner (user)
towsif = group
4096 = Directory size by bytes
Sep 8 18:36 = Last modification time
files = Directory name

** chmod u+x a.txt ---> to give execution permission
Explanation,
chmod = change mode
u+x = to give the user execution permission
a.txt = to this file

** chmod u-w a.txt ---> to remove write permission from the user
** chmod g-r a.txt ---> to remove write permission from the group
** chmod o+x a.txt ---> to give execution permission to others
** chown newUser file.txt ---> chown (change ownership) of the particular file to the newUser


User 2 types ==> root, normal
Group 2 types ==> primary (gid), supplementary
